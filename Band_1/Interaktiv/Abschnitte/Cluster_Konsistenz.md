## Cluster A: "Das Geisterhaus" (11-32)

**Pfad:** Direkt zum Herrenhaus → Zaun → Fenster → rein

**Orte besucht:**
- Herrenhaus (ab Abschnitt 11)
- Schuppen (optional, 14b)
- Dorfarchiv (optional, 15)
- Keller (23-24)
- Tunnel (25)
- Schatzkammer (26)
- Werkstatt (27)
- Mühle (Ausgang, 27)

**Was sie wissen (zusätzlich zum Start):**
- Mechanische Spuk-Effekte (Drähte, Seilzüge) — Winter hat sie gebaut
- Gemälde im Salon hat Mechanismus
- Geheimraum mit Uhr und Symbol
- Tunnelkarte (Haus → Mühle)
- W-Schlüssel passt im Keller
- Werkstatt mit Bauplänen der Mechanismen
- Meier besucht das Haus heimlich (Lehm an Schuhen)

**Was sie NICHT wissen:**
- Unterirdische Quelle / Wassersystem (= Cluster B)
- Details zum Diebstahl-Prozess 1994 (= Cluster C)
- Krügers persönliche Geschichte / der Brief (= Cluster D)
- Dass Krüger den Tunnel mitgebaut hat

**Gegenstände:**
- W-Schlüssel, Tunnelkarte, Truhe-Inhalt

## Cluster B: "Das Wasser-Abenteuer" (41-59)

**Pfad:** Zur Mühle → Tunnel entdecken → Wasserfall → Schatzkammer → (optional) ins Herrenhaus

**Orte besucht:**
- Mühle (41)
- Tunnel unter der Mühle (43)
- Unterirdischer See / Wasserfall (45)
- Höhle mit Wandmalereien (46)
- Schatzkammer (49)
- Herrenhaus — **ERSTES MAL** (Abschnitt 53, nur bei EP-B5 "Warten")

**Was sie wissen (zusätzlich zum Start):**
- Unterirdische Quelle unter der Mühle
- Quelle = Brunnen-Wahrheit (Karte in Höhle)
- Winter hat das Wasser 1989 gefunden (Glasflaschen)
- Wasserversorgungspläne in der Schatzkammer
- Rohr-Zeichnungen (Ben versteht sie)
- Meier geht nachts ins Herrenhaus

**Was sie NICHT wissen:**
- Mechanische Spuk-Effekte / Werkstatt (= Cluster A)
- Details zum Diebstahl-Prozess 1994 (= Cluster C)
- Krügers persönliche Geschichte / der Brief (= Cluster D)
- Dass Krüger den Tunnel mitgebaut hat

**ACHTUNG bei Abschnitt 53:**
- Kinder betreten das Herrenhaus zum ERSTEN MAL
- Kein "wie vorher", "diesmal", "wieder"
- Gemälde mit UNBESTIMMTEM Artikel ("ein Gemälde", nicht "das Gemälde")
- Keine Vorkenntnisse über Raumaufteilung

**Gegenstände:**
- W-Schlüssel, Wasserversorgungspläne, Truhe-Inhalt

## Cluster C: "Die Dorf-Detektive" (66-86)

**Pfad:** Im Dorf Informationen sammeln → Archiv/Bürgermeister → Ermittlung → Schatzkammer

**Orte besucht:**
- Meiers Laden (67)
- Frau Becker (68)
- Dorfarchiv (69) ODER Bürgermeister (70)
- (Je nach Weg) Mühle + Tunnel + Schatzkammer (75/76)
- ODER Herrenhaus direkt (74) → Meier fängt sie

**Was sie wissen (zusätzlich zum Start):**
- Winter war Dorfkassierer, des Diebstahls beschuldigt (1994)
- 5.000 Mark aus Dorfkasse
- Winters Verteidigungsbrief: "Ich bin unschuldig"
- Quittungen: Winter hat zurückgezahlt, obwohl unschuldig
- Fotos der drei echten Diebe
- Meier kommt aus der Erde / hat Tunnel-Zugang
- Prozessunterlagen in der Schatzkammer

**Was sie NICHT wissen:**
- Unterirdische Quelle / Wassersystem (= Cluster B)
- Mechanische Spuk-Effekte / Werkstatt (= Cluster A)
- Krügers persönliche Geschichte / der Brief (= Cluster D)

**Gegenstände:**
- W-Schlüssel, Prozessunterlagen, Quittungen, Truhe-Inhalt

## Cluster D: "Krügers Brief" (91-105)

**Pfad:** Krüger nachlaufen → zu ihm nach Hause → seine Geschichte → der Brief → Schatzkammer (mit Krüger)

**Orte besucht:**
- Krügers Haus (92-95)
- Mühle + Tunnel + Schatzkammer (100-101, **NUR mit Krüger zusammen**)
- Brunnen (optional, 99b)

**Was sie wissen (zusätzlich zum Start):**
- Krüger und Winter waren beste Freunde ("wie Brüder")
- Sie haben den Tunnel zusammen gegraben (2 Jahre)
- Winter hat das Herrenhaus gekauft und Archive gesammelt
- Beim Prozess hat Krüger geschwiegen (Feigheit)
- Der Brief: 30 Jahre ungeöffnet, Inhalt "Vergib dir selbst"
- Krüger führt sie persönlich zur Schatzkammer

**Was sie NICHT wissen (ohne Krüger):**
- Unterirdische Quelle / Wassersystem (= Cluster B)
- Mechanische Spuk-Effekte / Werkstatt (= Cluster A)
- Diebstahl-Prozess-Details und Beweise (= Cluster C)

**ACHTUNG bei Abschnitt 105 (Bad Ending):**
- Kinder gehen OHNE Krüger zum Herrenhaus
- Sie waren vorher NIE im Herrenhaus (Pfad: 7→91→92→105)
- Kein "wir waren schon drin", keine "gefundenen Sachen"
- Denkmalamt ist schneller → sie kommen gar nicht rein

**Gegenstände:**
- W-Schlüssel, Brief-Inhalt, Truhe-Inhalt (nur wenn Krüger mitkommt)

## Häufige Fehlerquellen

| Fehlertyp | Beispiel | Warum falsch |
|-----------|----------|--------------|
| Falscher Fundort | "Schlüssel vom Zaun" | Schlüssel = Brunnen (Abschnitt 7) |
| Vorwissen-Artikel | "Das Archiv", "Die Archive" | Bestimmter Artikel suggeriert Vorwissen |
| Wiederholungs-Sprache | "wie vorher", "diesmal", "wieder" | Impliziert früheren Besuch |
| Cross-Cluster-Wissen | Wasser-Details in Cluster A | Cluster sind unabhängig |
| Gegenstand ohne Fundort | Kinder haben X, aber nie gefunden | Nur Gegenstände aus eigenem Pfad |
| Falsche Krüger-Zitate | "Krüger hatte gesagt: Die Mühle..." | Krüger sagt im Common Start NUR: "Räume, die man nicht sieht" + "Bleibt weg". Mühle wird NIE erwähnt. Cluster-spezifische Zitate nicht übertragen! |
