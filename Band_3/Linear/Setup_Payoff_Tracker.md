## C. Regeln fuer die Pflege

1. Neuer Hinweis im Text -> sofort als Zeile in Tabelle A eintragen.
2. Payoff geschrieben -> Kapitel-Nummer + Status "erledigt" eintragen.
3. Faires Spiel: Ein Payoff in Kap N darf NUR Hinweise nutzen, die in Tabelle A
   mit "gesaet <= N" stehen. Sonst = Hut-Trick -> Hinweis frueher einbauen.
4. Vor Abschluss Band 3: keine Zeile darf "offen" sein (ausser bewusst Band-4).
