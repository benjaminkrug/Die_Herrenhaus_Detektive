# Cross-Referenz-Analyse — Band 2 Interaktiv

## Methodik

Jeder Abschnitt wurde gelesen und auf folgende Kategorien geprueft:
- **NAV** = Navigations-Fehler (Link zeigt auf nicht-existierende Datei)
- **OBJ** = Objekt-Fehler (Gegenstand benutzt/erwaehnt der auf diesem Pfad nicht existiert)
- **WISSEN** = Wissens-Fehler (Information erwaehnt die nur in anderem Cluster gelernt wird)
- **ZEIT** = Timeline-Fehler (unmoeglich zeitliche Abfolge)
- **CHAR** = Charakter-Fehler (Person anwesend die nicht da sein sollte)
- **BESCHR** = Beschreibungs-Fehler (physische Details widersprechen sich)
- **LOGIK** = Logik-Fehler (etwas ergibt keinen Sinn)

Schwere-Stufen:
- **SCHWER** = Logik-Bruch, Leser merkt es sofort, muss gefixt werden
- **MITTEL** = Inkonsistenz, aufmerksamer Leser merkt es, sollte gefixt werden
- **LEICHT** = Stilistisch/kosmetisch, nur bei Gelegenheit
