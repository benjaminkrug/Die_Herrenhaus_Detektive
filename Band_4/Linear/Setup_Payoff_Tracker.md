> Zweck: Faires Detektiv-Spiel sichern (Tschechows Gewehr).

> JEDE Aufloesung MUSS vorher fair angedeutet worden sein.

> geschrieben. `geschrieben` = im Kapiteltext tatsaechlich vorhanden (beim
> Schreiben umstellen). `offen` = bewusst fuer Band 5.
>
> **Vor der "fertig"-Erklaerung von Band 4 pruefen:** Hat JEDE Zeile in Tabelle A

## D. Regeln fuer die Pflege

1. Neuer Hinweis im Text -> **sofort** als Zeile in Tabelle A eintragen.
2. Payoff geschrieben -> Kapitelnummer eintragen, Status auf `geschrieben`.
3. **Faires Spiel:** Ein Payoff in Kap N darf NUR Hinweise nutzen, die in
   Tabelle A mit "gesaet <= N" stehen. Sonst = Hut-Trick -> Hinweis frueher
   einbauen.
4. **Umgekehrt genauso:** Wird beim Schreiben ein Setup gestrichen, muss sein
   Payoff mitgeprueft werden.
5. Vor Abschluss Band 4: keine Zeile in A oder B darf offen sein (ausser C).
